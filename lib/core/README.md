# Core Module

This directory contains core functionality shared across the entire application.

## Subdirectories
- `constants/`: Constant values (API endpoints, keys, strings).
- `theme/`: App styling, colors, and text styles.
- `utils/`: Helper functions and extensions.
- `widgets/`: Reusable generic widgets (Buttons, Inputs, etc).
- `router/`: Navigation configuration (GoRouter).
- `network/`: API clients (Dio setup).
