# Tech Stack

This document outlines the libraries and tools used in this project.

## Core
- **Flutter**: The framework used for building the application.
- **Dart**: The programming language.

## State Management
- **[flutter_riverpod](https://pub.dev/packages/flutter_riverpod)**: A reactive caching and data-binding framework. It is used for managing app state and dependency injection.

## Navigation
- **[go_router](https://pub.dev/packages/go_router)**: A declarative routing package for Flutter that supports deep linking, navigation guards, and nested routes.

## Networking
- **[dio](https://pub.dev/packages/dio)**: A powerful HTTP client for Dart. It supports interceptors, global configuration, FormData, request cancellation, file downloading, timeout etc.

## Data Modeling & Code Generation
- **[freezed](https://pub.dev/packages/freezed)**: Code generation for immutable classes and unions.
- **[json_serializable](https://pub.dev/packages/json_serializable)**: Automatically generate code for converting to and from JSON.
- **[build_runner](https://pub.dev/packages/build_runner)**: A build system for Dart, used to run code generation tasks.

## Testing
- **flutter_test**: Standard Flutter testing package.
